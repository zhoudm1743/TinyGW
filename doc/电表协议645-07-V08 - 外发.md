# 电表645-2007通信协议

## 1.1读数据

### 1.1.1 主站请求帧

功能：请求读电能表数据

控制码： C=11H

数据域长度： L=04H+m （数据长度）

帧格式1(m=0):

<!-- 68H A0 ... A5 68H 11H 04H DIo ... DI3 CS 16H 地址域 控制码 数据域长度 数据标识 -->
![](https://web-api.textin.com/ocr_image/external/b101c095d3b859b9.jpg)

### 1.1.2 从站正常应答

控制码： C=91H无后续数据帧；C=B1H有后续数据帧。

数据域长度： L=04H+m （数据长度）

无后续数据帧格式：

<!-- 68H A0 ... A5 68H 91H L DIo ... DI3 N1 ... Nm CS 16H 数据 -->
![](https://web-api.textin.com/ocr_image/external/2b942f4f84e781e8.jpg)

### 1.1.3从站异常应答帧

控制码：（C=D1H

数据域长度：L=01H

帧格式：

<!-- 68H A0 ... A5 68H D1H 01H ERR CS 16H 错误信息字 -->
![](https://web-api.textin.com/ocr_image/external/e47dee34b8de0588.jpg)

注： 错误信息字ERR见附录。

## 1.2 写数据

### 1.2.1 主站请求帧

功能：主站向从站请求设置数据（或编程）

控制码： C=14H

数据域长度： L=04H+04H(密码)+04H（操作者代码）+m（数据长度）

数据域：DI0DI1DI2DI3+PAP0P1P2+COC1C2C3+DATA

帧格式：

<!-- 68H A0 ... A5 68H 14H L DIo ... DI3 PA P0 P1 P2 CO ...C3 N1 ...Nm CS 16H 密码 操作者代码 -->
![](https://web-api.textin.com/ocr_image/external/45a87c9d5b6a6336.jpg)

1:POP1P2为密码，PA表示该密码权限。

2:COC1C2C3是操作者代码，为要求记录操作人员信息的项目提供数据。

3：本命令必须与编程键配合使用。

数据域长度： L=08H

帧格式：

<table border="1" ><tr>
<td colspan="1" rowspan="1">68H </td>
