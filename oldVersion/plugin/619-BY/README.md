# 619系列4G CAT1远传水表通讯协议插件

## 协议概述

本插件实现了**福建百悦信息科技有限公司**的619系列4G CAT1远传水表通讯协议。该协议基于CJ/T 188-2004规约，采用CAT1物联网通讯技术，支持水表的远程数据采集、控制和管理。

## 协议特点

- **起始帧**: 0x68
- **结束帧**: 0x16  
- **表类型**: 0x10 (水表)
- **设备类型**: 0x03
- **地址格式**: 14位BCD码，低字节在前
- **校验方式**: 累加和校验，取低8位

## 帧结构

```
起始帧(0x68) | 表类型(0x10) | 表地址(7字节) | 设备类型(0x03) | 控制码 | 指令编号(2字节) | 备用(2字节) | 数据长度 | 数据域 | 校验码 | 结束帧(0x16)
```

## 支持的控制码

| 控制码 | 说明 |
|--------|------|
| 0x01   | 服务器对表端下发读指令 |
| 0x04   | 服务器对表端下发写指令 |
| 0x17   | 服务器对表端上报的响应 |
| 0x81   | 表端对服务器读指令的响应 |
| 0x84   | 表端对服务器写指令的响应 |
| 0x97   | 表端主动上报 |

## 支持功能

### 1. 数据读取
- **表参数读取**: 读取水表基本参数信息
- **实时数据采集**: 定时读取水表数据

### 2. 阀门控制
- **开阀操作**: 远程开启阀门
- **关阀操作**: 远程关闭阀门

### 3. 系统管理
- **时钟校对**: 同步水表时钟

### 4. 数据解析
- **主动上报解析**: 解析水表主动上报的数据
- **电压监测**: 监测电池电压状态
- **用量统计**: 累计用量、剩余量等数据解析

## 数据包类型

| 类型 | 说明 |
|------|------|
| 0x01 | 预付费普通表上报 |
| 0x02 | 预付费阶梯表上报 |  
| 0x03 | 后付费表上报 |
| 0x04 | 调试信息上报 |
| 0x05 | 运行状态上报 |
| 0x06 | 检测报告上报 |

## 使用方法

### 在系统中配置设备

1. 在设备管理界面添加新设备
2. 选择协议类型为 `619-BY`
3. 设置设备地址（14位数字）
4. 配置通讯参数

### 自定义命令

插件支持以下自定义命令：

#### 读取表参数
```json
{
  "command": "read_params"
}
```

#### 开启阀门
```json
{
  "command": "open_valve"
}
```

#### 关闭阀门
```json
{
  "command": "close_valve"
}
```

#### 时钟校对
```json
{
  "command": "sync_clock"
}
```

## 解析的数据变量

| 变量名 | 说明 | 数据类型 | 单位 |
|--------|------|----------|------|
| voltage | 电池电压 | int | mV |
| total_usage | 累计用量 | double | L |
| remain_usage | 剩余量 | double | L |
| daily_usage | 日用量 | double | L |
| read_response | 读取响应 | string | - |
| write_response | 写入响应 | string | - |

## 注意事项

1. **地址格式**: 设备地址必须是14位数字，不足时前面补0
2. **数据精度**: 用量数据精度为0.01L，系统会自动处理小数点
3. **校验机制**: 所有指令都包含校验码，确保通讯可靠性
4. **错误处理**: 插件包含完整的错误处理机制，会输出详细的调试信息
