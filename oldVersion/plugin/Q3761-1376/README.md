# Q/GDW 1376.1 协议插件

本插件基于 `doc/3761-BY.md` 文档实现了 Q/GDW 1376.1 电力通信协议。

## 功能特性

### 支持的AFN（应用功能码）
- `AFN=00H` 确认/否认
- `AFN=01H` 复位命令  
- `AFN=02H` 链路接口检测（登录、心跳、退出登录）
- `AFN=04H` 设置参数
- `AFN=09H` 请求终端配置及信息
- `AFN=0AH` 读取参数
- `AFN=10H` 数据转发

### 支持的命令

1. **login** - 登录命令
   - 功能：终端向主站登录
   - 参数：无
   - 示例：`{"cmd": "login"}`

2. **heartbeat** - 心跳命令  
   - 功能：保持连接，附带当前时间
   - 参数：无
   - 示例：`{"cmd": "heartbeat"}`

3. **logout** - 退出登录
   - 功能：终端退出登录
   - 参数：无
   - 示例：`{"cmd": "logout"}`

4. **transparent** - 透明转发
   - 功能：透明转发数据到指定端口
   - 参数：
     - `port`: 端口号（默认1）
     - `timeout`: 超时时间秒（默认30）
     - `data`: 要转发的数据数组
   - 示例：`{"cmd": "transparent", "params": {"port": 1, "timeout": 30, "data": [0x68, 0xAA, 0xAA, 0x68, 0x11]}}`

5. **version** - 读取终端版本
   - 功能：读取终端版本信息
   - 参数：无
   - 示例：`{"cmd": "version"}`

6. **module_version** - 读取模块版本
   - 功能：读取通信模块版本信息（IMEI等）
   - 参数：无
   - 示例：`{"cmd": "module_version"}`

## 协议格式

### 帧结构
```
68H | L | L | 68H | C | A | AFN | SEQ | DA | DT | DATA | CS | 16H
```

- `68H`: 帧起始符
- `L`: 长度域（2字节重复）
- `C`: 控制域
- `A`: 地址域（5字节：行政区划码2字节 + 终端地址2字节 + 主站地址1字节）
- `AFN`: 应用功能码
- `SEQ`: 帧序列域
- `DA`: 信息点标识（2字节）
- `DT`: 信息类标识（2字节）
- `DATA`: 数据内容
- `CS`: 校验和
- `16H`: 帧结束符

### 地址示例
- 行政区划码：4154H
- 终端地址：4924H  
- 完整地址：41544924
